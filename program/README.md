# Файлы программы для отчета

Тема: **Разработка системы учета возвратов и гарантийных случаев товаров**.

В папке находится решение Visual Studio:

- `WarrantyReturns.sln` - общее решение Visual Studio;
- `desktop-wpf` - десктопное приложение для менеджера магазина «Компонент»;
- `mobile-maui` - мобильное приложение .NET MAUI для инженера сервисного центра.

## Запуск через Visual Studio

1. Открыть файл `program/WarrantyReturns.sln` в Visual Studio 2022.
2. Убедиться, что установлены workloads:
   - `.NET desktop development`;
   - `.NET Multi-platform App UI development`.
3. Для мобильной сборки в Visual Studio Installer также должны быть установлены компоненты Android:
   - `Android SDK setup`;
   - `Android SDK Platform`;
   - `Android Emulator`;
   - `Microsoft.Android` / .NET Android workload.
4. Для запуска десктопной версии выбрать проект `WarrantyReturns.Desktop`.
5. Для запуска мобильной версии выбрать проект `WarrantyReturns.Mobile` и Android Emulator / устройство.

Если при сборке мобильного проекта появляется ошибка:

```text
NETSDK1127: пакет нацеливания Microsoft.Android не установлен
```

нужно открыть **Visual Studio Installer → Modify / Изменить → Individual components / Отдельные компоненты** и установить Android-компоненты для .NET MAUI. После установки перезапустить Visual Studio и выполнить **Restore NuGet Packages**.

## Десктопное приложение

Технологии: C# + WPF.

Основные функции:

- добавление заявок на возврат и гарантийный случай;
- редактирование статуса заявки;
- поиск и фильтрация по статусу;
- сохранение данных в локальный JSON-файл;
- синхронизация через общий файл `cloud/warranty_cases.json`;
- экспорт реестра в `.docx` и `.xlsx`;
- простое логирование действий.

Альтернативный запуск на Windows через терминал:

```bash
cd program/desktop-wpf
dotnet run
```

## Мобильное приложение

Технологии: C# + .NET MAUI.

Основные функции:

- просмотр заявок инженером;
- фильтрация по статусу;
- изменение статуса;
- добавление технического заключения;
- сохранение изменений в локальный JSON-файл приложения;
- подготовка синхронизационной копии данных для обмена с десктопной частью/облаком.

Запуск через Visual Studio:

1. Открыть `WarrantyReturns.sln`.
2. Выбрать проект `WarrantyReturns.Mobile`.
3. Выбрать Android Emulator.
4. Нажать `Start Debugging`.

## Данные

Для демонстрации используется общий файл:

```text
program/cloud/warranty_cases.json
```

Десктопное приложение использует этот файл как демонстрационный аналог облачной синхронизации. MAUI-приложение хранит данные в локальном каталоге приложения и может формировать синхронизационную копию для обмена.
