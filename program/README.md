# Файлы программы для отчета

Тема: **Разработка системы учета возвратов и гарантийных случаев товаров**.

В папке находятся два прототипа:

- `desktop-wpf` - десктопное приложение для менеджера магазина «Компонент»;
- `mobile-kivy` - мобильное приложение для инженера сервисного центра.

## Десктопное приложение

Технологии: C# + WPF.

Основные функции:

- добавление заявок на возврат и гарантийный случай;
- редактирование статуса заявки;
- поиск и фильтрация по статусу;
- сохранение данных в локальный JSON-файл;
- синхронизация через общий файл `cloud/warranty_cases.json`;
- экспорт реестра в `.docx` и `.xlsx`;
- простое логирование действий.

Запуск на Windows:

```bash
cd program/desktop-wpf
dotnet run
```

## Мобильное приложение

Технологии: Python + Kivy.

Основные функции:

- просмотр заявок инженером;
- фильтрация по статусу;
- изменение статуса;
- добавление технического заключения;
- сохранение изменений в общий файл синхронизации.

Запуск:

```bash
cd program/mobile-kivy
python -m pip install -r requirements.txt
python main.py
```

## Данные

Для демонстрации используется общий файл:

```text
program/cloud/warranty_cases.json
```

Десктопное приложение создает его при первой синхронизации. Мобильное приложение читает и обновляет этот же файл.
